🧠 SMI-V Plus

ระบบรายงาน "ร้อยละของผู้ป่วยจิตเวชสารเสพติดก่อความรุนแรง (SMI-V) ในเขตสุขภาพเข้าถึงบริการได้รับการดูแลต่อเนื่องและไม่ก่อความรุนแรงซ้ำ" ตามรายงานมาตรฐาน HDC

คู่มือส่งมอบระบบ (หน้านี้เป็นเอกสารสถิต ไม่ใช่ตัวระบบที่ใช้งานจริง)
⚠️ หน้านี้คือคู่มือส่งมอบ ไม่ใช่ระบบที่ใช้งานได้จริง ระบบ SMI-V Plus เป็นเว็บแอป PHP + MySQL ที่ต้องรันบนเซิร์ฟเวอร์จริง (Docker) — GitHub Pages โฮสต์ได้แค่ไฟล์ static (HTML/CSS/JS) จึงรัน login, ฐานข้อมูล, นำเข้า/ส่งออก Excel หรือ AI ไม่ได้ในหน้านี้ ต้อง deploy ตามขั้นตอนด้านล่างเพื่อใช้งานจริง

ระบบทำอะไรได้บ้าง

📥 นำเข้าข้อมูล Excelรองรับไฟล์ exchange_file.xlsx (ชีต Data) ผ่านหน้าเว็บโดยตรง — ทดสอบแล้วนำเข้าสำเร็จ 1,482 แถว
📊 Dashboard ครบวงจรKPI, กราฟ 8+ ชนิด, ตารางรูปแบบ HDC Template ในหน้าเดียว
🗺️ มุมมองหลายระดับรายอำเภอ / รายหน่วยบริการ / รายจังหวัด พร้อมกรองช่วงวันที่และเลือกพื้นที่เจาะจง
🤖 สรุปด้วย AIเรียก Ollama (LLM ท้องถิ่น) สรุปสถานการณ์เป็นภาษาไทย
🔍 วิเคราะห์ปัญหาอัตโนมัติกฎเกณฑ์ตรวจสอบย้อนกลับได้ (ไม่ใช่ black-box) พร้อมข้อเสนอแนะเชิงปฏิบัติ
📤 ส่งออก Excelรายงานสรุปและ "รายชื่อผู้ป่วยที่มีปัญหา" พร้อมคำแนะนำ ส่งคืนพื้นที่ตรวจสอบได้ทันที
📖 คู่มือรหัส SMI-Vอ้างอิงรหัส 1B030-1B037 และตาราง Z-code ที่มักลงผิด ในตัวระบบ
🔐 ระบบผู้ใช้Login + สิทธิ์ admin/viewer, ล็อกบัญชีอัตโนมัติเมื่อลองรหัสผิดหลายครั้ง

สถานะการตรวจสอบข้อมูล

ทดสอบกับข้อมูลจริง 1,482 แถว (7 อำเภอ จ.มุกดาหาร):

รายการตรวจผล
PID ซ้ำ (hoscode+pid)ไม่พบ
รหัส b03x นอกช่วง 1B030-1B033ไม่พบ
วันที่ผิดปกติ (เกิดหลังวันรับบริการ, ติดตามก่อนวันแรก)ไม่พบ
อายุ ณ สิ้นปีงบผิดปกติไม่พบ
ข้อมูลอ้างอิงตำบล/อำเภอไม่ครบพบ 1 ราย (chw_addr/ampur/tambon ว่าง)

เริ่มต้นใช้งานจริง (Deploy)

Stack: PHP 8.2 (Apache) + MySQL 8 + PhpSpreadsheet + Docker Compose

git clone https://github.com/thering999/smiv_plus.git
cd smiv_plus
cp .env.example .env    # ตั้งรหัสผ่านฐานข้อมูลใหม่
docker compose up -d --build
docker compose exec web composer install
docker compose exec web php bin/create_admin.php admin "รหัสผ่านที่ปลอดภัย"

เปิด http://localhost:8081/ (หรือโดเมน/พอร์ตที่ตั้งค่าไว้บนเซิร์ฟเวอร์จริง)

สูตรคำนวณหลัก (อ้างอิงเอกสาร HDC Template)

ตัวแปรความหมาย
B / C / Dผู้ป่วยเก่า / ใหม่ / รวม (D=B+C)
Hประชากร 15-60 ปี ย้อนหลัง 2 ปี (กรอกเอง)
Iผู้ป่วยประมาณการณ์ = H × 4.37% × 11.92% (คำนวณอัตโนมัติ)
Eอัตราเข้าถึงบริการ = D/I×100 (เป้า >40%)
J,K,L / M,N,Oติดตาม 1 ครั้ง / ติดตาม ≥2 ครั้ง และอัตราไม่ก่อซ้ำ

"ก่อความรุนแรงซ้ำ" นับจากจำนวนรหัส b03x (1B030-1B033) ที่ถูกลงทะเบียน มากกว่า 1 ครั้ง ต่อผู้ป่วย — รายละเอียดเต็มดูที่ README.md

ข้อจำกัดที่ต้องทราบ

  • ยังไม่ตัดผู้เสียชีวิตออกจากตัวนับ (ไม่มีช่องทางเชื่อมฐานข้อมูลกระทรวงมหาดไทย)
  • ข้อมูลประชากร (H) ต้องกรอกเองรายอำเภอ ไม่ได้มาจากไฟล์นำเข้า
  • สรุปด้วย AI ต้องมี Ollama รันอยู่บนเครื่อง/เครือข่ายเดียวกัน
