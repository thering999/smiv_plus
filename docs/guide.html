คู่มือเจ้าหน้าที่ — SMI-V Plus

ติดตามผู้ป่วยจิตเวชสารเสพติดก่อความรุนแรง (SMI-V) รายคน · เว็บ: thering999.github.io/smiv_plus

⚠️ ข้อมูลส่วนบุคคล (PDPA)

  • ชื่อ / เลขบัตร / ที่อยู่ผู้ป่วย ใช้เพื่อติดตามดูแลเท่านั้น — ห้ามถ่ายรูปหน้าจอ ส่งไลน์ หรือส่งต่อนอกหน่วยงาน
  • ระบบบันทึกทุกครั้งที่เข้าสู่ระบบและเปิดดูข้อมูล (ผู้ดูแลตรวจย้อนหลังได้)
  • ใช้บัญชีของตัวเองเท่านั้น · กด 🔒 ออกจากระบบ ทุกครั้งเมื่อใช้เครื่องร่วมกับผู้อื่น · ใบงานที่พิมพ์ต้องทำลายเมื่อใช้เสร็จ

1. เข้าสู่ระบบ

  1. เปิดเว็บ แล้วกรอก ชื่อผู้ใช้ / รหัสผ่าน ในการ์ด 🔐
  2. เห็นเฉพาะผู้ป่วยอำเภอที่รับผิดชอบ (ภูมิลำเนาในมุกดาหาร)
  3. เซสชันอยู่ได้ 8 ชม. · ผิด 5 ครั้ง ล็อก 15 นาที
  4. หน้าจอไม่อัปเดต → กด Ctrl+F5

2. ดูว่าต้องติดตามใคร

  1. เลื่อนไปที่ รายชื่อผู้ป่วยที่ต้องติดตาม
  2. 🔴 สูง = ก่อความรุนแรงซ้ำ (ติดตามก่อน) · 🟠 กลาง · ⚪ ปกติ
  3. ป้าย ⏰ เกินนัด บนแถบด้านบน → กดเพื่อดูเฉพาะคนที่เลยวันนัด
  4. ค้นหาด้วยชื่อ / หน่วยบริการ / ตำบล ได้

3. บันทึกการติดตาม (ทุกครั้ง)

  1. กด 📝 บันทึก ในแถวของผู้ป่วย
  2. เลือก สถานะ เช่น เยี่ยมบ้านแล้ว / โทร / ไม่พบตัว / ส่งต่อ / ปิดเคส
  3. ใส่ วันนัดครั้งถัดไป — ระบบจะเตือนเมื่อเลยวันนัด
  4. บันทึกสั้นๆ (ไม่เกิน 500 ตัวอักษร) แล้วกด บันทึก

4. ก่อนลงพื้นที่

  • 🖨️ พิมพ์ใบงานติดตาม — 1 หน้าต่อหน่วยบริการ มีช่องเขียนผล
  • 📋 ส่งออกรายชื่อปัญหา — Excel พร้อมสถานะติดตามล่าสุด
  • กลับมาแล้ว บันทึกผลในระบบ ให้ครบ

สถานะการติดตาม — เลือกอันไหน

สถานะใช้เมื่อ
เยี่ยมบ้านแล้วพบตัวผู้ป่วย/ญาติที่บ้าน
ติดตามทางโทรศัพท์คุยกับผู้ป่วย/ญาติได้ทางโทรศัพท์
ไม่พบตัวไปแล้วไม่พบ / ติดต่อไม่ได้ — ใส่วันนัดลองใหม่
ปฏิเสธการรักษาผู้ป่วยไม่ยอมรับการรักษา — แจ้งทีมสุขภาพจิตอำเภอ
ส่งต่อส่งต่อโรงพยาบาล/หน่วยงานอื่น
อาการคงที่รับยาต่อเนื่อง ไม่มีพฤติกรรมรุนแรง
ปิดเคสย้ายออก / เสียชีวิต / ไม่ต้องติดตามแล้ว (ไม่ขึ้นเตือนเกินนัดอีก)

ผู้ดูแลระบบ (admin) เท่านั้น

  • นำเข้าข้อมูลใหม่: เลือกไฟล์ Excel จาก HDC (ชีต Data) → กด 🚀 เผยแพร่ข้อมูล — ระบบเตือนเลขบัตรไม่ครบ 13 หลักเป็นปกติของไฟล์ HDC กดยืนยันได้
  • ผู้ป่วยนอกจังหวัด: กดการ์ด "นอกจังหวัด" → 🗺️ ส่งออก Excel แยกชีตตามจังหวัด เพื่อประสานส่งต่อ
  • ตรวจการเข้าถึงข้อมูล: 📜 ประวัติการนำเข้า → บันทึกการเข้าถึงข้อมูล (PDPA)
  • ผลงานรายเดือน: ในแผงความครอบคลุมการติดตาม → 📈 ผลงานการติดตามรายเดือน

ติดปัญหา

  • เข้าสู่ระบบไม่ได้ / ลืมรหัส / ย้ายอำเภอ → ติดต่อผู้ดูแลระบบ (สร้างบัญชีให้ใหม่ได้ทันที)
  • ไม่เห็นรายชื่อ ขึ้นว่า "ยังไม่มีข้อมูลผู้ป่วยตัวจริง" → รอผู้ดูแลเผยแพร่ข้อมูลรอบใหม่
  • ข้อมูลผู้ป่วยผิด (ชื่อ/ที่อยู่/วันรับบริการ) → แก้ที่ระบบ HIS ของโรงพยาบาล รอบถัดไปจะถูกต้องเอง
